# plant-leaf-nutrient-deficiency-detection
Deep learning project using CNN to detect plant leaf nutrient deficiencies from images. Includes image annotation, preprocessing, and data augmentation. Built with TensorFlow and Keras, it predicts conditions like Nitrogen deficiency with confidence scores, supporting smart agriculture and precision farming.
# Plant Leaf Nutrient Deficiency Detection Using Deep Learning

## 📌 Project Overview
This project uses Deep Learning and CNN to detect plant leaf nutrient deficiencies from images. It helps in early detection of plant health issues for smart agriculture.

## 🎯 Objective
To automatically classify plant leaf conditions like Nitrogen deficiency using image processing and CNN models.

## 📊 Dataset
- Plant leaf images
- Healthy and nutrient-deficient classes
- Annotated dataset with bounding boxes

## 🖼️ Image Annotation
Images were labeled using bounding boxes to mark affected leaf regions and assign class labels like Nitrogen deficiency.

## ⚙️ Methodology
- Image preprocessing (resize, normalization)
- Data augmentation (rotation, flip, zoom)
- CNN model building using TensorFlow/Keras
- Training and evaluation

## 🧠 Model
- Convolutional Neural Network (CNN)
- ReLU activation
- Max pooling layers
- Softmax output layer

## 📈 Results
- Achieved good accuracy in classification
- Model predicts nutrient deficiency with confidence score

## 🚀 Future Scope
- Mobile app deployment
- Real-time detection
- IoT integration for smart farming

## 🛠️ Technologies Used
Python, TensorFlow, Keras, OpenCV, NumPy, Matplotlib
